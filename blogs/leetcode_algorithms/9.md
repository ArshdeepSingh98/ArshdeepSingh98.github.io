- Use stack to get the **just** next Greater or next Smaller (vice versa for prev) element for each element in array

## Code (Python)
```python
class Solution:
    def nextGreaterElements(self, nums: List[int]) -> List[int]:
        n = len(nums)
        mono = nums[::-1]
        res = [-1] * n
        i = n-1


        for num in nums[::-1]:
            # remove all the smaller next elements
            while mono and mono[-1] <= num:
                mono.pop()
            # next greater element
            if mono:
                res[i] = mono[-1]
            mono.append(num)
            i -= 1
       
        return res
```
