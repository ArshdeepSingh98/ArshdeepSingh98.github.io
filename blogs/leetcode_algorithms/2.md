Used to calculate shortest path in a graph problem (negative weights are allowed)

## Code (Python)
```python
def findCheapestPrice(self, n: int, flights: List[List[int]], src: int, dst: int, k: int) -> int:
    prices = [inf]*n
    prices[src] = 0

    for i in range(k+1):
        temp = prices.copy()
        for s, d, price in flights:
            if prices[s] != inf:
                temp[d] = min(prices[s] + price, temp[d])
        prices = temp
    
    return temp[dst] if temp[dst] != inf else -1
```
