Used to calculate shortest path in a graph problem

## Time Complexity
- O(V) (adding vertices) +( O(log(E)) (heap pop) + O(E) (checking edges) + O(log(E) (adding to the PQ) ) * E (at most all edges are traversed)
- $O(V + ElogE)$

## Space Complexity
- adj list O(V) + result/shortest distance map O(V) + min heap to store edge weight for each node at worst O(V)
- $O(V)$

## Code (Python)
```python
class Solution:
   def shortestPath(self, n: int, edges: List[List[int]], src: int) -> Dict[int, int]:
       adj = {}
       for i in range(n):
           adj[i] = []

       for s, t, wt in edges:
           adj[s].append([t, wt])

       res = {}
       minHeap = [[0, src]]
       while minHeap:
           w1, n1 = heapq.heappop(minHeap)
           if n1 in res:
               continue
           res[n1] = w1
          
           for n2, w2 in adj[n1]:
               if n2 not in res:
                   heapq.heappush(minHeap, [w2 + w1, n2])
       for i in range(n):
           if i not in res:
               res[i] = -1
       return res
```
