- MST = Minimum Spanning Tree
- A subset of a graph's edges that connects all the vertices while using the least amount of edge weight 
- **Algorithm**: Same as Dijkstra’s just weight of the neighbors is considered instead of sum of weights of neighbor and current node

## Code (Python)
```python
 def minCostConnectPoints(self, points: List[List[int]]) -> int:
       adj = defaultdict(list)
       def dist(x, y):
           return abs(x[0] - y[0]) + abs(x[1] - y[1])

       for i in range(len(points)):
           for j in range(i+1, len(points)):
               p1, p2 = points[i], points[j]
               d = dist(p1, p2)
               adj[i].append([j, d])
               adj[j].append([i, d])
      
       visited = set()
       minHeap = [[0, 0]]
       res = 0

       while len(visited) < len(points):
           w1, s1 = heapq.heappop(minHeap)
           if s1 in visited: continue
           visited.add(s1)
           res += w1

           for nei, w2 in adj[s1]:
               if nei not in visited:
                   heapq.heappush(minHeap, [w2, nei])
      
       return res

```
