## Steps 
### 1. Global Development Visualization

Steps:

- Data Collection & Preprocessing:
    - Obtained the dataset from the CORGIS Dataset Project (World Bank data).
    - Cleaned and formatted data to ensure consistency across different years and attributes.
- Data Manipulation & Structuring:
    - Parsed data using JavaScript for smooth integration with D3.js.
    - Structured the data for multi-line plotting, ensuring dynamic updates.
    - Visualization Development:
        - Implemented D3.js to create an interactive multi-line chart.
        - Designed responsive UI using Bootstrap and CSS for user-friendly interactions.
        - Enabled user selection of countries and attributes to dynamically update the visualization.
    - Interactivity & Enhancements:
        - Integrated tooltips and transitions for a seamless user experience.
        - Optimized rendering for performance across different datasets.

### 2. Space Dogs Custom Innovative Visualization

Steps:

- Data Preparation:
    - Collected data on Soviet space dogs and their missions.
    - Structured the dataset to allow visualization of different years and shuttle movements.
- Custom Visualization Design:
    - Developed a unique visualization model outside standard libraries.
    - Designed an interactive animated shuttle orbiting system to reflect historical events.
- Implementation & User Interaction:
    - Used JavaScript and D3.js to create an interactive environment.
    - Allowed users to select a year and trigger dynamic shuttle movement.
- Refinements & Enhancements:
    - Added smooth animations for an engaging experience.
    - Ensured cross-browser compatibility and responsiveness.

These projects highlight expertise in data visualization through interactive and dynamic representations, demonstrating proficiency in D3.js, JavaScript, Bootstrap, and custom visualization techniques.
