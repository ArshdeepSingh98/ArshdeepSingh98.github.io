This project is a chatbot application that allows users to interact with PDF documents using natural language. It integrates **LangChain** and **Ollama** for local LLM processing, with a **ReactJS** frontend and a **FastAPI** backend for scalability.
Key Features:


## Architecture
- PDF Interaction – Extracts and processes information from PDFs using natural language commands.
- LangChain & Ollama – Provides language understanding and inference using Meta’s LLaMa model for local processing.
- Vector Database (Qdrant) – Stores documents and efficiently retrieves context via vector queries.
- FastAPI Backend – Stateless, horizontally scalable API handling asynchronous requests.
- ReactJS Frontend – Delivers a modern and responsive UI for user interactions.

    def answer_question_for_a_document(self, question, doc_id):
        doc_path = config.UPLOAD_DIRECTORY + "/" + doc_id
        retriever = vector_db.get_retriever(doc_path)
        retrieval_chain = create_retrieval_chain(retriever, self.document_chain)
        return retrieval_chain.invoke({"input": question})["answer"]
